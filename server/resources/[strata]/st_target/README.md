# st_target

Performant third-eye targeting for the Strata framework.

Provides entity, model, zone, and global option targeting for clients, with framework hooks for Strata jobs, groups, and items.

## Usage

Hold the configured hotkey (default `LMENU`) to begin targeting. Convars are defined in `server/config/st_target.cfg`.

## Compatibility

`provide 'qtarget'` is set so resources that depend on `qtarget` continue to resolve.
